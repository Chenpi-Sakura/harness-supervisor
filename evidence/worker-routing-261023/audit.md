# 独立审计记录

独立只读审计 Agent 先检查源码与已编译代码，通过 scratch 复现发现三个 P1：compact 并发遗失新请求、幂等坏尾粘连、CJK 大事件恢复丢失。初始相关单测虽通过，三个针对性复现失败，因此没有以单测通过替代审计。

负责人/真实 Pi Worker 修复后，独立 Agent 针对最终 dist 再验证：

- compact 并发新增 key 保持 `running`，原子替换期间更新旧 key 可 `replay`，不重复准入。
- 坏尾后的新准入标记重启可恢复为 `uncertain`。
- 新写入超限 CJK 事件明确 `truncated`，旧合法 2.4 MB CJK 事件完整恢复。
- append 失败经普通 flush 报告、缓存逐出后，完整历史仍明确失败。
- 重启时缺失已确认日志或序号缺口被识别。
- 最终 idempotency、store、notify 单测 47/47 通过。

最终结论：原三个 P1 已修复，未发现新增阻断缺陷。Worker/事件路由快照、ack/重试未发现阻断问题；异步 wait 先订阅、dirty 重评估和退订未发现丢唤醒竞态。

保留 P2：`wait(until:'event', types:...)` 仅检查游标后的前 500 条，命中事件位于后页且 Worker 仍运行时可能超时。这是既有分页限制，不阻断本轮 P0 路由交付。

审计未编辑代码、未操作生产 Daemon，不替代真实宿主 E2E。本文件是审计结论的精简归档；相关确定性回归位于仓库测试中。
